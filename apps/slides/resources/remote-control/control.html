鼠标模拟
若点击无效，再换注入引擎（决定由什么进程来注入）：
注入诊断：等待一次点击…
方式1＝SendInput 独立按下/抬起（与 Python pynput 完全同款）；方式2＝先用 SetCursorPos 钉住光标再 SendInput；方式3＝老 mouse_event；方式4＝PostMessage 直投窗口。
引擎1＝常驻隐藏进程（默认）；引擎2＝常驻但显示 PowerShell 窗口（用于验证“无窗口进程被区别对待”，弹窗请勿关闭）；引擎3＝每次点击新起一个进程（最慢，约1-2秒，但进程形态与手动运行 Python 服务一致）。
点一次左/右键后看上方诊断：返回 1~2 说明系统已接受注入（问题在目标程序）；返回 0 说明被系统拒绝。
